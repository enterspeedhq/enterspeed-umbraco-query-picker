# Enterspeed Umbraco Query Picker

**Note: This is a reference project, not a production-ready package. It shows how to use Enterspeed as a picker in Umbraco for content that lives outside Umbraco, such as a PIM, an ERP, or any other system whose data you’ve ingested into Enterspeed.**

**The repo is not maintained and dependencies are not being updated.**

## Setup

Navigate to the `src/Client` folder and run the following commands:

```bash
npm install
npm run build
```

Reference the `src/Enterspeed.Umbraco.QueryPicker.csproj` project file from you Umbraco website project.

The Query picker project is now installed and you can start your Umbraco website.
